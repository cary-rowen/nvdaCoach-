NVDA Coach — Treinamento e ajuda adicionais

Use os recursos desta página para continuar sua jornada de aprendizado do NVDA.

Recursos do NVDA Coach

  • Guia do usuário do NVDA Coach — Documentação completa do complemento NVDA Coach, com todos os atalhos de teclado, as descrições das lições e as opções de personalização.
  • Página de prática do NVDA Coach — A página web usada nas lições de modo de navegação. Abra quando quiser para praticar a navegação por títulos, links, formulários, tabelas e listas.
  • NVDA Coach no GitHub — Código-fonte, registro de problemas, downloads das versões e histórico de versões.

Recursos oficiais do NVDA

  • NV Access — A organização que cria e mantém o NVDA. Baixe a versão mais recente, obtenha suporte e faça uma doação para manter o NVDA gratuito.
  • Ajuda e suporte do NVDA — Documentação oficial, fóruns da comunidade e opções de suporte.
  • Guia do Usuário do NVDA (on-line) — A referência completa do NVDA, com todos os recursos e comandos.

Recursos de acessibilidade web e de leitores de tela

  • WebAIM — Guias práticos e artigos sobre acessibilidade web, incluindo técnicas de leitor de tela e navegação pelo teclado.
  • WebAIM: usar o NVDA para avaliar a acessibilidade web — Um guia prático para usar o NVDA na navegação web e nos testes de acessibilidade.
  • Iniciativa de Acessibilidade Web do W3C (WAI) — Normas e diretrizes internacionais para um design web acessível.
