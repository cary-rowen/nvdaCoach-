Página de Prática do NVDA Coach

Sobre esta página

Bem-vindo à página de prática do NVDA Coach. Esta página foi criada especialmente para praticar a navegação com leitor de tela. Ela tem títulos, links, um formulário, uma tabela e listas — tudo o que você precisa para praticar as habilidades ensinadas no NVDA Coach.

Você pode percorrer esta página no modo de navegação usando os atalhos de teclado que está aprendendo. Não é preciso clicar em nada. Tudo aqui é para praticar, então fique à vontade para explorar.

Como usar esta página

Basta pressionar as teclas de navegação que a sua lição do NVDA Coach está ensinando. Por exemplo, pressione H para saltar entre os títulos, K para saltar entre os links e F para saltar entre os campos de formulário. Use a Seta para Baixo para ler linha a linha, ou a Leitura Contínua para ler a página inteira (NVDA+Seta para Baixo no esquema de computador de mesa, NVDA+A no esquema de computador portátil).

Prática de leitura de texto

Esta seção tem parágrafos mais longos para você praticar a leitura e a navegação. O NVDA consegue ler todo este texto com a Leitura Contínua. No esquema de computador de mesa, pressione NVDA+Seta para Baixo; no esquema de computador portátil, pressione NVDA+A. Você pode parar a leitura a qualquer momento pressionando Control.

A história dos leitores de tela

Os leitores de tela existem desde os anos 1980. Os primeiros eram programas simples que convertiam em fala, por meio de sintetizadores, o texto exibido na tela. Com o tempo, ficaram muito mais sofisticados e aprenderam a interpretar imagens, páginas web e layouts complexos.

Hoje, leitores de tela como o NVDA, o JAWS e o VoiceOver conseguem ler conteúdo web, planilhas, e-mails e documentos com uma precisão notável. O NVDA, sigla de NonVisual Desktop Access, foi lançado em 2006 e se tornou um dos leitores de tela mais usados do mundo, em boa parte por ser gratuito e de código aberto.

Por que praticar faz diferença

Aprender um leitor de tela leva tempo e repetição. Os atalhos de teclado podem parecer estranhos no começo, mas com a prática eles ficam automáticos. A maioria dos usuários experientes percorre páginas web e documentos em alta velocidade, usando a navegação por títulos, a navegação por marcos e as listas de links para achar informação rapidinho.

O segredo é praticar um pouco todo dia. Concentre-se em um conjunto de comandos de cada vez, use esses comandos em situações reais e vá ganhando velocidade e confiança aos poucos. O NVDA Coach foi feito para ajudar você a fazer exatamente isso.

Prática de listas

Esta seção tem uma lista não ordenada e uma lista ordenada. Pressione L para saltar para a próxima lista. Pressione I para andar entre os itens de uma lista.

Comandos essenciais do NVDA (lista não ordenada)

  • NVDA+T — Ler a barra de título da janela atual
  • NVDA+Tab — Anunciar o foco atual
  • NVDA+Seta para Cima — Ler a linha atual
  • NVDA+Seta para Baixo (computador de mesa) / NVDA+A (computador portátil) — Leitura Contínua a partir da posição atual
  • NVDA+F12 — Anunciar as horas (pressione duas vezes para a data)
  • NVDA+1 — Ligar ou desligar o modo de ajuda de entrada
  • NVDA+F7 — Abrir a Lista de Elementos
  • NVDA+Espaço — Alternar entre o modo de navegação e o modo de foco
  • Control — Interromper a fala
  • NVDA+N — Abrir o menu do NVDA

Passos para percorrer uma página web nova (lista ordenada)

  1. Pressione NVDA+T para confirmar em que página você está.
  2. Pressione H para percorrer os títulos e ter uma visão geral da estrutura da página.
  3. Pressione D para saltar até o marco do conteúdo principal, pulando a navegação.
  4. Pressione a Seta para Baixo para ler o conteúdo da página.
  5. Use o K para encontrar e seguir os links que precisar.
  6. Use o F e o E para preencher os formulários da página.
  7. Pressione NVDA+F7 para ter a lista completa de links ou de títulos, se precisar encontrar algo específico.
