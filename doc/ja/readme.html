NVDAコーチ について

NVDAコーチ は、短時間の実践的な練習セッションを通じてスクリーンリーダーのコマンドを教えます。マニュアルでコマンドを読むのではなく、音声を聞きながらその場で実際に試します。各レッスンでは1つのコマンドずつ案内し、あなたが試すのを待ってから次へ進みます。NVDAコーチ は自分のペースで段階的に学べるように設計されています。

このプログラムは、文字、数字、矢印キー、Enter、Escape、Tab など、キーボードの基本的な感覚をすでに掴んでいる初心者を対象にしています。NVDAコーチ は、支援技術指導者の Tony Gebhard によって作成されました。

使い始める

NVDA+Shift+C を押すと NVDAコーチ が開きます。画面には Coach ウィンドウが表示されたままになります。初めて開いたときは、紹介文とレッスン選択画面が表示されます。矢印キーでレッスンを選び、Enter キーを押して開始してください。

レッスン選択画面では、右矢印キーでセクションを展開し、左矢印キーで折りたたみます。Enter キーまたは「開く / 開始」ボタンを押すと、選択したアイテムが開始されます。

Coach ウィンドウは学習中ずっと開いたままなので、指示はいつでも手元にあります。練習のために別のウィンドウへ移動した場合は、レッスン中いつでも NVDA+Shift+C を押して Coach ウィンドウに戻れます。

レッスン中

各レッスンは、短い一連のステップで進みます。NVDA のコマンドを試すステップでは、別のウィンドウに切り替えて操作を行い、終わったら NVDA+Shift+C を押して Coach ウィンドウに戻り、Enter キーまたは「次のステップ」を押して続けてください。練習用テキストがあるステップでは、Coach ウィンドウ内のテキストエリアへ下矢印キーで移動し、そのまま練習できます。レッスン中は、次のキーがいつでも使えます:

  • Enter: ステップを試したことを確認し、次へ進む。
  • F1: 現在の指示を繰り返す。NVDA にもう一度読み上げてもらいたい時に使います。
  • F2: ヒントを聞く。もう一度押すと追加のヒントが出ます。1つのステップにつき最大3つまで順に聞けます。
  • F3: 現在のステップをスキップして進む。
  • Escape: レッスンを停止する。3回押すと NVDAコーチ を閉じます。
  • NVDA+Shift+C: 別のウィンドウから Coach ウィンドウに戻る。

レッスンのナビゲーション

レッスンを終えたら、レッスン選択画面を開き直さなくても次へ進めます:

  • Ctrl+N: 現在のチャプターの次のレッスンへ進む。
  • Ctrl+B: 前のレッスンに戻る。
  • Ctrl+R: 現在のレッスンを最初からやり直す。
  • NVDA+Shift+C: レッスン選択画面を開き、任意のレッスンやチャプターへ移動する。

収録レッスン

1. NVDA をはじめよう

初心者にとって不可欠な NVDA コマンドを学びます。各レッスンは1分から3分程度の短い練習です。

  1. コマンドのカテゴリーを理解する — キーボードコマンドを制御する3つの層（Windows、使用中のアプリケーション、スクリーンリーダー）と、NVDA のコマンドが情報を読み上げるだけで内容を変更しない理由。
  2. NVDAキーについて — NVDA の修飾キー（Insert または Caps Lock）を見つけて使い、NVDA+N で NVDA メニューを開く。
  3. タイトルバーを読み上げる — NVDA+T で、いま使っているプログラムをいつでも確認する。
  4. 時刻を読み上げる — NVDA+F12 で現在の時刻と日付を聞く。
  5. バッテリー残量を確認する — NVDA+Shift+B で、バッテリー残量と充電中かどうかを聞く。
  6. NVDA の読み上げを止める — Control キーで音声をすぐに停止する。
  7. 現在の場所を確認する — NVDA+Tab で、フォーカスがあるコントロールを確認する。練習用ログインフォームが開きます。
  8. Tab キーでコントロール間を移動する — Tab と Shift+Tab でダイアログやフォームを移動する。練習用フォームが開きます。
  9. ボタンとコントロールを実行する — Enter キーでボタンを実行し、スペースキーでチェックボックスを切り替える。練習用のコントロールが開きます。
  10. 現在の行を読み上げる — NVDA+上矢印キーで現在の行をいつでも読み直す。練習用テキストエリアが付いています。
  11. 入力ヘルプでキーを確認する — NVDA+1 で、どのキーが何をするかを安全に確認する。
  12. ユーザーガイドを開く — NVDA メニューの「ヘルプ」から NVDA のユーザーガイドを開く。
  13. キーボードの理解 — Control キーの位置の違い、Fn+矢印キーによる Home/End/Page Up/Page Down、マルチメディア操作と F キーの2つのモード、そして修飾キーの位置の復習。
  14. Alt+Tab によるウィンドウの切り替え — Alt+Tab を1回押して2つのウィンドウを行き来し、Alt を押したまま Tab を叩いて複数のウィンドウを順に確認する。

2. あなたのキーボード

物理的なキーボードの理解 — 修飾キーの場所、ファンクションキー、Fn キーの挙動、そして NVDA の配列設定との合わせ方を学びます。

  1. 修飾キーとその場所 — 標準キーボードとラップトップでの Control、Shift、Alt、Windows キー、そして NVDAキー（Insert と Caps Lock）の位置。日本語キーボードでの注意点も含みます。
  2. ファンクションキーと Fn キー — F1 から F12、マルチメディア操作と F キーの2つのモード、Fn+矢印キーによる Home/End/Page Up/Page Down、そして Fn Lock。
  3. デスクトップ配列対ラップトップ配列 — 配列設定の意味、確認と変更の方法、そして NVDAコーチ がどのレッスンでも両方の配列の操作を併記する理由。

3. テキストの読み上げと移動

文書内を移動し、NVDA にテキストを読み上げさせる方法を学びます。各練習ステップには、Coach ウィンドウ内にテキストエリアが含まれているため、別のウィンドウを開く必要はありません。

  1. 文字単位の移動 — 右矢印キーと左矢印キーで、テキストを一文字ずつ進む。
  2. 単語単位のジャンプ — Control+右矢印キーと Control+左矢印キーで、単語単位に移動する。
  3. 行単位の移動 — 下矢印キーと上矢印キーで、文書を一行ずつ読み進める。
  4. 先頭と末尾へのジャンプ — Control+Home と Control+End で、文書の先頭と末尾へ即座に移動する。
  5. ここからすべて読み上げる — 連続読みは止まらずに読み上げます。デスクトップ配列は NVDA+下矢印キー、ラップトップ配列は NVDA+A。
  6. テキストの選択とハイライト — Shift+矢印キーで文字、単語、行を選択し、Control+C でコピーする。選択範囲の読み上げは、デスクトップ配列なら NVDA+Shift+上矢印キー、ラップトップ配列なら NVDA+Shift+S。
  7. 段落とページ単位の移動 — Control+上矢印キーと Control+下矢印キーで段落単位に移動し、Page Up と Page Down でさらに大きく移動する。
  8. フォントと書式を確認する — NVDA+F で、カーソル位置のフォント名、サイズ、太字、斜体、下線を聞く。

4. ブラウズモードとウェブナビゲーション

NVDA のブラウズモードを使って、ウェブページや HTML 文書を操作する方法を学びます。レッスンを開始すると、練習用のウェブページが自動的に開きます。

  1. ブラウズモードについて — ブラウズモードとは何か、そしてブラウザへの切り替え方。
  2. 見出し単位の移動 — H と Shift+H で、ページの見出し間を移動する。
  3. 見出しレベルへのジャンプ — 1 から 6 の数字キーで、指定したレベルの見出しへ移動する。
  4. リンク単位の移動 — K と Shift+K でリンク間を移動し、Tab キーで操作可能な要素間を移動する。
  5. フォームを操作する — F、E、B で、フォーム項目、入力欄、ボタンへ移動する。
  6. フォーカスモード対ブラウズモード — NVDA+スペースで、読み上げと文字入力を切り替える。フォーカスモードではカーソルが入力欄の中に置かれます。
  7. ランドマークとリスト — D でランドマーク間を、L でリスト間を移動する。
  8. 要素リスト — NVDA+F7 で、ページ内のすべての見出し、リンク、フォーム項目、ランドマークの一覧を開く。
  9. ページ内のテキストを検索する — NVDA+Control+F でページ内を検索し、NVDA+F3 と NVDA+Shift+F3 で結果を前後に移動する。
  10. 表の操作 — Control+Alt+矢印キーで表のセル間を移動する。表に入ったときに NVDA が何を読み上げるか。

5. オブジェクトナビゲーション

Tab キーでは到達できないコントロールなどを、NVDA のオブジェクトナビゲーションコマンドを使って操作する方法を学びます。

  1. オブジェクトナビゲーションとは？ — ピラミッドの階層モデル、使うべき場面、そして先にウィンドウを最大化しておくことの大切さ。
  2. 次・前のオブジェクトへの移動 — NVDA+NumPad6 と NVDA+NumPad4（デスクトップ配列）、NVDA+Shift+右矢印 と NVDA+Shift+左矢印（ラップトップ配列）。NVDA+Tab との違いも扱います。
  3. 階層の上り下り — NVDA+NumPad8 と NVDA+NumPad2（デスクトップ配列）、NVDA+Shift+上矢印 と NVDA+Shift+下矢印（ラップトップ配列）。
  4. 現在のオブジェクトを読み上げる — NVDA+NumPad5（デスクトップ配列）、NVDA+Shift+O（ラップトップ配列）。素早く2回押すと、名前を一文字ずつ読み上げます。
  5. フォーカスをオブジェクトへ移動する — NVDA+Shift+NumPadマイナス（デスクトップ配列）、NVDA+Shift+BackSpace（ラップトップ配列）で、ナビゲーターが指しているオブジェクトへフォーカスを移動する。
  6. どんなときに役立つか — オブジェクトナビゲーションが役立つ3つの場面と、練習のすすめ。

6. NVDA のカスタマイズ

NVDA のキーボード配列、読み上げ速度、声の種類などを自分の好みに合わせて調整する方法を学びます。このチャプターを完了すると、修了証を書き出せるようになります。

  1. キーボード配列の変更 — NVDA の設定で、デスクトップ配列（テンキー）とラップトップ配列（文字キー）を切り替える。
  2. 簡単音声設定 — 設定ダイアログを開かずに、読み上げの速さ、高さ、音量、声の種類を変更する。項目の切り替えは、デスクトップ配列なら NVDA+Control+右矢印 と NVDA+Control+左矢印、ラップトップ配列なら NVDA+Shift+Control+右矢印 と NVDA+Shift+Control+左矢印。
  3. 出力先の変更 — NVDA+Control+U で「オーディオ出力デバイスの選択」を開き、ヘッドホンや外部スピーカー、HDMI に切り替える。
  4. オーディオダッキングの制御 — NVDA+Shift+D で、NVDA が話している間に他の音量を下げるモードを切り替える。

練習環境

多くのレッスンには練習環境が組み込まれており、レッスンを離れずに実際のコマンドを試せます:

  • 練習用フォーム — Tab キーでの移動、コントロールの実行、フォーカスの確認を扱うレッスンでは、本物のボタン、チェックボックス、入力欄を備えた別のフォームウィンドウが開きます。「Tabキー移動の練習用フォーム」、「コントロールの実行の練習」、「フォーカスを探す — 練習用ログインフォーム」の3つがあります。
  • 練習用テキストエリア — 読み上げとテキスト移動のレッスンでは、Coach ウィンドウ内に練習エリアが用意されています。指示から下矢印キーでテキストへ移動すれば、文字、単語、行の移動や選択を、ウィンドウを切り替えずに練習できます。
  • 練習用ページ — ブラウズモードのレッスンでは、練習用のウェブページがブラウザで開きます。見出しの移動、リンク、フォーム、表、リストの練習のためにいつでも開くことができます。

進捗の記録

NVDAコーチ は、完了したレッスンを記憶します。完了したレッスンはレッスン選択画面に「[完了]」と表示され、チャプターごとに「14 個中 5 個完了」のように進み具合が分かります。進捗は NVDA のユーザー設定フォルダに保存され、NVDA を再起動しても残ります。

指導者の方へ

レッスンは、アドオンの lessons フォルダにプレーンな JSON ファイルとして保存されています。各 JSON ファイルが1つのレッスンカテゴリーを定義し、その中に順序付きのレッスンの一覧が入ります。そして各レッスンは、ステップの一覧になっています。ステップには、学習者が読んで Enter キーを押す説明型のもの、学習者が自分で操作してから Enter キーで確認するコマンド型のもの、そしてウィンドウ内での移動練習のためのテキストエリアを含むものがあります。新しい JSON ファイルを追加すれば、独自のレッスンカテゴリーを作成できます。同梱のファイルをひな形としてご利用ください。
